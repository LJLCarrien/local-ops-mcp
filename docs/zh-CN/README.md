# Local Ops 中文文档

这里的文档使用占位符替代个人路径、Tunnel ID、代理端口和项目名称。

## 按场景选择

| 你现在要做什么 | 阅读哪一篇 |
|---|---|
| 第一次理解并搭建完整方案 | [零基础教程](./ChatGPT本地文件访问-零基础教程.md) |
| 已经理解原理，想查配置项或快速配置 | [Tunnel 配置速查](./ChatGPT本地文件访问-Tunnel配置速查.md) |
| 把现有配置迁移到另一台电脑 | [换电脑只看这一页](./换电脑只看这一页.md) |

## 阅读顺序

第一次使用建议先看零基础教程。配置成功后，日常只需要保存“Tunnel 配置速查”；配置来源和重新初始化判断也在其中。换电脑时再看迁移专题，不必重新通读全部教程。

## 分享前仍要检查

这些文档本身已经脱敏，但发布配套截图、日志或个人修改版之前，仍需删除：

- Runtime API Key 或其他密钥；
- 真实 Tunnel ID、组织 ID 和 Workspace ID；
- Windows 用户名、私人项目名与真实绝对路径；
- 代理端口、邮箱、浏览器标签和账号信息。
