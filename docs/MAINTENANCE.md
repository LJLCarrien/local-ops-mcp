# 文档维护地图

每类操作事实只保留一个权威来源，其余场景文档链接到该来源。公开文档目前只维护简体中文。

| 信息类型 | 权威文档 |
|---|---|
| 项目概览、工具范围、Git 行为、功能开关和安全边界 | 根目录 `README.md` |
| 概念与首次学习路径 | `zh-CN/ChatGPT本地文件访问-零基础教程.md` |
| 配置项、启动、重新初始化、ChatGPT 连接和排错 | `zh-CN/ChatGPT本地文件访问-Tunnel配置速查.md` |
| 换电脑时与首次安装不同的部分 | `zh-CN/换电脑只看这一页.md` |
| 插件目录安装细节 | `plugins/local-ops/README.md` |

## 编辑规则

1. 先在权威文档中修改操作事实。
2. 其他文档以短摘要和链接替代重复细节。
3. 换电脑指南只写与首次安装不同的内容；最小验证提示可以有意重复。
4. 插件 README 只保留插件安装细节，服务行为链接至根 README。
